ระบบทะเบียนหนังสืออิเล็กทรอนิกส์ - Frontend V1
สำนักงานสาธารณสุขอำเภอโนนสะอาด

ไฟล์:
1. index.html
2. config.js
3. app.js

วิธีใช้งาน:
- อัปโหลดทั้ง 3 ไฟล์ขึ้น GitHub repository เดียวกัน
- เปิด GitHub Pages ของ repository
- เปิดหน้าเว็บแล้วทดสอบด้วย user004 และรหัสผ่านที่ตั้งไว้
- Frontend จะเรียก Apps Script Web App URL ที่กำหนดไว้ใน config.js

หมายเหตุสำคัญ:
- V1 นี้ทำ Login + Dashboard + รายการเอกสาร + ดูรายละเอียด + Workflow + เปิดไฟล์ Drive
- ยังไม่ได้ทำฟอร์ม "รับหนังสือ" และหน้ากระบวนงานเต็มรูปแบบ เพื่อให้ทดสอบการเชื่อมต่อก่อน
- หาก Web App ถูก Deploy เป็นเวอร์ชันใหม่ ต้องใช้ URL /exec เดิมได้ หาก deployment เดิมอัปเดตเป็นเวอร์ชันล่าสุด
- ไม่เก็บรหัสผ่านใน localStorage; เก็บเฉพาะ session token และข้อมูลผู้ใช้ที่ API ส่งกลับ
