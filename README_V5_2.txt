ระบบทะเบียนหนังสืออิเล็กทรอนิกส์ สสอ.โนนสะอาด
V5.2

สิ่งที่ปรับปรุง
1. UI ใหม่แบบ Sidebar ซ้าย + พื้นที่ทำงานกลาง ลดหน้าเว็บยาว
2. Dropdown กลุ่มงาน -> งาน สำหรับหนังสือรับและระบบออกหนังสือ
3. โหลดข้อมูลจาก ORG_UNITS เดิม ไม่สร้างรหัสกลุ่มงาน/งานใหม่
4. Backend ตรวจสอบความสัมพันธ์ Group/Job ก่อนบันทึก
5. ADMIN มีหน้า “จัดการผู้ใช้งาน” และตั้งรหัสผ่านชั่วคราวจากหน้าเว็บ
6. Temporary password จะบังคับผู้ใช้เปลี่ยนรหัสผ่านเมื่อเข้าสู่ระบบครั้งแรก
7. แก้ Logout ให้ซ่อนพื้นที่ระบบและ Modal
8. รายงานสรุปเบื้องต้นตามข้อมูลทะเบียนเดิม

ข้อสำคัญ
- ใช้ฐานข้อมูล Spreadsheet เดิม ห้ามสร้างฐานข้อมูลใหม่
- ไม่รีเซ็ต NUMBER_COUNTERS และไม่ลบเอกสารเดิม
- Apps Script ให้มี Backend หลักเพียงไฟล์เดียวที่ประกาศ const API_CFG
- หลังนำ code.gs V5.2 ไปแทน Backend เดิม ต้อง Deploy Web App เป็นเวอร์ชันใหม่
- config.js ใช้ URL Web App เดิม หากแก้ Deployment แบบ New version ของ Deployment เดิม URL จะคงเดิม
- รหัสผ่านจริงไม่เก็บใน source code หรือ Google Sheets แบบ plaintext

หมายเหตุเรื่อง Temporary Password
V5.2 ใช้ฟิลด์ MustChangePassword ที่มีอยู่ใน USERS เดิม จึงไม่เพิ่มคอลัมน์ฐานข้อมูลใหม่ในรุ่นนี้ ระบบจะไม่แสดงรหัสผ่านเดิมของผู้ใช้ และรหัสชั่วคราวจะแสดงให้ ADMIN ทราบเพียงตอนตั้งค่าเท่านั้น
